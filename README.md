# 终末地 · 工业配平器 / Endfield Ratio Planner

**在线使用：<https://xxz1894-collab.github.io/mrfz/>**

明日方舟：终末地 工业系统的**配平计算器**（纯静态网页，无框架、无构建）。

输入任意可生产产物与目标产能（件/分钟），自动拆解整条生产链，算出每道工序用哪台设备、放几台、总耗电、需要多少外部原料，并单列副产物。

- **配平计算**：选目标产物 + 产能，生成工序表、设备台数、耗电、原料、副产物，可切换任一道工序的替代配方。
- **物品图鉴**：179 个物品的获取途径（资源点抽取 / 种植 / 采种 / 拆解 / 工厂生产 / 野外采集）与自动化生产流程图。
- **配方总表**：358 条配方，可按产物、原料搜索，按设备过滤。
- **生产设备**：26 座生产设备的耗电、占地、带宽、接口数与配方列表。

数据来自 [终末地 Wiki（fz.wiki）](https://www.fz.wiki/) 的建筑与配方条目，2026-11-08 抓取；非官方玩家工具，与鹰角网络无关。

## 本地运行

```powershell
python -m http.server 8787 --bind 127.0.0.1 --directory .
```

打开 <http://127.0.0.1:8787/>。直接双击 `index.html`（file://）无法加载 `data.json`，必须走 http。

## 算法摘要

1. 选路：从目标产物 BFS，每个产物按评分挑一条配方，过滤「原料含产物自身」的自指回收线。
2. 物料平衡：把链看成线性方程组，不动点迭代求每条配方执行次数，收敛后反推需求与副产物。
3. 台数：`需求 ÷ 单机产能` 向上取整；副产物不抵扣，单列提示。
4. 循环链（砂叶⇄砂叶种子、赤铜耐压罐⇄气体等）联立求解并标记；无法闭合时逐项换配方，仍不行则按外部采购处理并提示。
